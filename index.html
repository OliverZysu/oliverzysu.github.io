个人简介

我是苏梓阳，目前是上海交通大学计算机科学与技术专业博士生，导师为郑冠杰老师，在约翰·霍普克罗夫特计算机科学中心的 City Intelligence Lab（CILAB）开展研究。

我的研究兴趣包括大规模图神经网络优化、交通生成与生成式推荐。相关研究涉及城市级路网数据、融合 POI 的交通流生成，以及跨业务交易中的用户生命周期价值预测。

我于 2022 年获得电子科技大学学士学位，同年进入上海交通大学攻读博士学位。

我正在寻找全职工作机会，欢迎通过邮件联系。

论文与研究

The ACM Web Conference

CoGSeq-LTV: Scalable Missing-Aware Graph-Sequence Modeling for Multi-Business Transaction Analytics [paper][code]

Ziyang Su, Yao Zhou, Kelin Liu, Guanjie Zheng, Linghe Kong

WWW 2027·第一作者

提出面向多业务、多周期用户生命周期价值预测的缺失感知图序列模型，结合批内用户商品图、业务专属序列编码与跨视图对比学习。通过零膨胀混合对数正态分布建模稀疏长尾消费，并在真实交易数据及后续时间窗口上验证预测效果。

The ACM Web Conference

DualClusterNet: Personalized Pattern-Space Composition for Next-POI Recommendation [paper][code]

Ziyang Su, Guanjie Zheng, Jilin Hu, Linghe Kong

WWW 2027·第一作者

提出基于轨迹前缀的模式与空间双原型软分配，通过因子化乘性交互组合共享行为模式和空间情境。结合用户仿射调制、独立个性化分支与加性及投影门控融合，在完整 POI 候选集上实现兼顾群体规律与个体偏好的下一地点推荐。

International Conference on Learning Representations

Multi-task Prediction of Solid-phase Extraction Protocol Components from Molecular Descriptors [paper][code]

第一作者：Ziyang Su

ICLR 2027

提出从分子描述符联合预测固相萃取柱、步骤、溶剂集合及配比的多任务框架，以集合监督保留文献中的多种可选组分，并对缺失配比标注进行掩码处理。结合 Rank-Gauss 归一化、验证集校准解码和自助采样集成，提高已记录组分的恢复质量并降低配比预测误差。

International Conference on Machine Learning

OSM+: Billion-Level OpenStreetMap Dataset for City-wide Experiments [paper][code]

Guanjie Zheng, Ziyang Su, Yiheng Wang, Yuhang Luo, Hongwei Zhang, Xuanhe Zhou, Linghe Kong, Fan Wu, Wen Ling

ICML 2026·Spotlight·学生第一作者

构建全球十亿级节点的结构化路网图数据集，并提供分布式预处理流程与 SQL 空间查询接口，支持路网拓扑、几何及属性的高效获取。进一步构建覆盖 31 个城市的交通预测基准和 6 个城市的交通策略控制数据集，为城市级图学习与可扩展性研究提供统一数据支撑。

International Conference on Database Systems for Advanced Applications

Ziyang Su, Wentao He, Jiayuan Liu

DASFAA 2025·Poster·第一作者

International Conference on Database Systems for Advanced Applications

POI-based Traffic Generation via Supervised Contrastive Learning on Reconstructed Graph [paper][code]

Ziyang Su, Zhanyu Liu, Jianrong Ding, Guanjie Zheng

DASFAA 2024·Poster·第一作者

面向缺少历史交通数据的区域，利用 POI 信息构建 k 近邻图并聚合特征，以缓解原始路网结构对交通流生成的干扰。引入基于交通流相似性的监督对比学习，学习适用于交通流生成的 POI 表征，并在四个真实数据集上进行验证。
